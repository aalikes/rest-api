# SOP: Fingerprint Capture

## Overview
Standard operating procedure for capturing fingerprints on FD-258 cards.

## Equipment
- FD-258 fingerprint cards (blank)
- Ink pad (black)
- Card holder/stand
- Magnifying glass (quality check)
- Alcohol wipes (cleaning)

## Procedure

### 1. Client Check-In
- Verify appointment or accept walk-in
- Confirm service type and ORI code
- Check valid government-issued photo ID

### 2. Preparation
- Wash and dry client's hands
- Inspect fingers for cuts, bandages, or conditions affecting print quality
- Prepare FD-258 card with client information:
  - Full legal name
  - Date of birth
  - Social Security Number (if applicable)
  - ORI number
  - Reason for fingerprinting

### 3. Ink Capture
- Roll each finger from nail to nail in one smooth motion
- Capture all 10 rolled impressions
- Capture flat (plain) impressions of 4 fingers simultaneously
- Capture both thumbs flat

### 4. Quality Check
- Inspect each print for clarity
- Ensure no smudges or partial prints
- Re-roll any unsatisfactory prints on a new card if needed

### 5. Completion
- Have client verify information on card
- Provide client with confirmation number
- Card can be:
  - Mailed to requesting agency
  - Converted to PDF for client
  - Held for FBI submission

## Notes
- Cards can be sent as PDF — not electronically
- Professional ink cards only (not Live Scan for out-of-state)
- Average service time: 15–20 minutes
